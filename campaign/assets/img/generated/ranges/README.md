# Range card photography

Generated with the built-in image generation tool from the existing CHW product photography. Each image is a landscape 3:2 composition, with space above for the statistics and below for the overlapping text panel. Product photos remain unscaled by scroll animations.

Responsive WebP assets for each of `surgical`, `nutraceuticals`, and `herbal`:

- `*-480.webp`: 480 × 320
- `*-900.webp`: 900 × 600
- `*-1200.webp`: 1200 × 800

The 1536 × 1024 generated originals were resized proportionally and compressed with Sharp. Existing product assets are retained for other sections.
